## Skill 详细说明

`mokeaigc-v25` 是一套用于概念设计和视觉开发的创作 Skill。输入可以是一句话、一个世界观草案、一段场景描述或一张参考图。它先提炼用户已经确定的世界规则、物种结构或场景事实，再根据任务选择交付形式，把抽象设定转成可见的建筑、材质、生活行为、构图和光线。

| 我想做什么 | 选择 |
| --- | --- |
| 我有一个世界的点子，想知道那里的人怎么生活 | **A · 世界观** |
| 我想设计一只异兽，明确它的结构、习性和栖息地 | **B · 生物与怪物** |
| 我已有一场戏，想比较远景、近景、俯拍等拍法 | **C · 视觉构图** |

### 通用工作流程

1. **明确输入与范围。** 提供创作概念或参考图，说明已有设定、希望探索的内容和必须保留的元素。参考图可以用于画风、主体或构图，按指定用途提取可见特征。
2. **确定模式。** 世界观任务走 A，单独设计物种走 B，同一场景的多种拍法走 C。可直接指定模式和交付数量。
3. **确定视觉基调。** 支持按编号或名称选风格，例如 `35 上美水墨`、`29 三渲二`。也可以自定义，或输入 `0` 跳过。跳过时沿用已有视觉要求，未给要求时使用默认电影写实。只要文字设定可用 `模式 A，仅设定`，直接交付设定与关系说明。
4. **编写交付物。** 多张图共享统一的媒介、形体、线条和材质规则，允许按场景改变天气、光线与景别。每条提示词都能独立使用，中英文描述对应同一画面。
5. **核对一致性并出图。** 交付前核对设定、画面内容、中英描述和视觉媒介是否一致。需要实际图片时，把选中的提示词交给生图工具，按成图效果回调提示词或构图。

### 模式 A · 世界观

1. 用一句话确立世界的核心规则，例如「巨兽每三个月潜入海中，背上的城镇必须在入水前完成转移」。
2. 写出规则带来的具体后果。居住空间如何防水，粮食如何储存，居民用什么交通方式，资源如何分配，哪些群体会因此发生冲突。
3. 用世界差异表和 Mermaid 关系图整理关键关系，让环境、资源、制度和居民行为能互相解释。
4. 制定视觉规范，给出代表性设计图提示词和九张世界概览提示词。九个切面分别是**居民、动物、建筑、地景、日常、迁徙、声音或文化、权力或张力、肖像**。上方三联图选取了其中的地景、日常和迁徙进行演示。

### 模式 B · 生物与怪物

1. 从栖息地和生态位置推导体型、肢体结构、运动方式及环境适应特征。已有世界观时，继承它的规则和视觉基调。
2. 锁定各视图的共同特征，包括轮廓比例、肢体数量、器官位置、材质和配色。
3. 交付生物摘要与中英多视图设定表提示词。可按需加入器官细节面板，或补一张展示生物如何在栖息地活动的环境静帧提示词。

```text
$mokeaigc-v25
模式 B，选择 33 体素方块 3D。
设计生活在盐晶洞穴的六足食矿生物。
说明它如何攀爬、进食，给出结构一致的多视图提示词。
```

### 模式 C · 视觉构图

1. 用一两句话锁定人物、地点、动作和戏剧重心。例如「在山村木桥上，邮差把最后一封信交给守桥老人」。
2. 围绕同一事件设计拍法，用机位、景别、前后景、视线和空间关系拉开差异。例如远景交代两人和木桥的位置，过肩镜头看老人接信，近景聚焦手中的信封。
3. 默认交付九种方案。每种包含标题、构图意图和中英完整静帧提示词。透视画面可说明焦段，正交、等距或平面画面按实际构成描述。

```text
$mokeaigc-v25
模式 C，选择 29 三渲二。
山村木桥上，邮差把最后一封信交给守桥老人。
保留同一人物、地点和事件，给出 4 种构图，画幅 4:3。
```

### 风格库与交付设置

- **65 项视觉选项**包括 63 个可直接使用的预设，以及 `39`、`49` 两个需要指定作品、分集或参考图的入口。可请求查看完整列表，或按题材推荐最多三项。风格库索引在技能包内的 `references/style-index.md`。
- **切换画风**时沿用已有世界事实、生物结构和核心场景，调整线条、表面质感、色彩、光影等视觉表达。风格卡中的题材示例仅供理解画风。
- **平台与格式**默认 Midjourney、16:9、中英双语。可指定目标模型、画幅、语言和数量。Midjourney 的 `--sref`、`--profile` 仅沿用你提供的值。
- **输出范围**是文字设定与静帧图像提示词。实际图像由生图工具生成；视频运镜与连续动作需要单独制作。包内的 `references/workflow.md` 包含完整流程与交付模板。

## 快速开始

下载 V25 技能包，解压后将整个 `mokeaigc-v25` 文件夹放入所用助手的技能目录，保留 `SKILL.md`、`agents/` 和 `references/`。在支持技能调用的助手中选择 `mokeaigc-v25`，输入你的创作需求。

```text
$mokeaigc-v25
模式 A，选择 35 上美水墨。
设计一座建在巨兽背上的迁徙城市。巨兽每三个月会潜入海中一次。
说明居民如何安排居住、储粮和迁徙，并给出九张世界概览的中英静帧提示词。
```

V25 默认按 Midjourney、16:9、中英双语编写。可以指定其他模型、画幅、语言和提示词数量。将提示词交给你使用的图像工具即可出图。
