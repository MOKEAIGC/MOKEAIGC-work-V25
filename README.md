# MOKEAIGC · 世界观与视觉风格导演

从一句灵感或一张参考图出发，构建世界观、设计虚构生物，或为同一场景探索不同拍法。适用于 AI 短片、动画和游戏的前期概念设计。

## 快速开始

下载 V25 技能包，解压后将整个 `mokeaigc-v25` 文件夹放入所用助手的技能目录，保留 `SKILL.md`、`agents/` 和 `references/`。在支持技能调用的助手中选择 `mokeaigc-v25`，输入你的创作需求。

```text
$mokeaigc-v25
模式 A，选择 35 上美水墨。
设计一座建在巨兽背上的迁徙城市。巨兽每三个月会潜入海中一次。
说明居民如何安排居住、储粮和迁徙，并给出九张世界概览的中英静帧提示词。
```

V25 默认按 Midjourney、16:9、中英双语编写。可以指定其他模型、画幅、语言和提示词数量。将提示词交给你使用的图像工具即可出图。
